# 구조는 캔버스가 아니라 노트의 parents 가 정한다

- 주제: [[생각 정리 시스템]]
- 상위: [[생각 정리 시스템]]

## 핵심

`.canvas` 파일은 `node tools/vault.mjs canvas` 가 매번 다시 그리는 자동 생성물이다. 캔버스에서 노드를 끌어다 옮겨도 다음 실행에 사라진다. 단일 진실 원천은 각 노트 프론트매터의 `topic` 과 `parents` 다.

## 근거 / 맥락

이렇게 두면 구조 변경이 곧 텍스트 변경이라 git diff 로 "언제 생각의 구조가 바뀌었는지" 가 남는다. 캔버스를 손으로 편집하면 그 이력이 좌표 변화로만 남아 읽을 수 없다.

## 반론 / 빈 곳

대신 자유로운 공간 배치는 포기해야 한다. 레이아웃은 트리 하나뿐이다.
