## 기본 골격: 뱉기 → 갈래치기 → 층 나누기 → 캐묻기 → 압축

머릿속이 복잡한 이유는 대개 **생각이 많아서가 아니라, 서로 다른 층위의 생각이 한 덩어리로 붙어 있어서**다.
사실과 해석, 감정과 판단, 목표와 수단이 뒤엉킨 채로는 어느 것도 검증할 수 없다.
이 방법의 목표는 덩어리를 **검증 가능한 최소 단위**로 떼어내는 것이다.

### 1단계 — 뱉기 (Dump)

정리하지 않은 채로 다 말하게 둔다. 순서도 논리도 요구하지 않는다.

- 나(Claude)는 개입하지 않는다. `계속하세요.` 외에는 말하지 않는다.
- 말이 끊기면 딱 하나만 던진다: **"또 뭐가 걸려 있나요?"**
- 산출물: 원문 그대로의 텍스트 (→ 노션 "말한 내용")

### 2단계 — 갈래치기 (Split)

한 덩어리로 들린 이야기에서 **독립적으로 참/거짓을 따질 수 있는 조각**을 골라낸다.

기준: 그 문장 하나만 떼어놨을 때 "그래서 그게 맞아?" 라고 물을 수 있으면 조각 하나다.

- "요즘 일이 안 풀려서 방향을 바꿀까 싶은데 그러면 지금까지 한 게 아깝고" → 조각 3개
  1. 지금 일이 안 풀리고 있다 (사실 주장)
  2. 방향을 바꾸는 게 나을 수 있다 (판단)
  3. 지금까지 한 것이 아깝다 (매몰비용 감정)
- 산출물: 조각 목록 (아직 파일로 만들지 않는다)

### 3단계 — 층 나누기 (Layer)

각 조각에 층을 붙인다. 이게 이 방법의 핵심이다.

| 층 | 뜻 | 검증 방법 |
| --- | --- | --- |
| **사실** | 관찰한 것 | 증거를 댈 수 있나? |
| **해석** | 사실에 붙인 의미 | 다르게 해석할 여지는? |
| **감정** | 그래서 느낀 것 | 이게 판단을 밀고 있나? |
| **판단** | 그래서 내린 결론 | 어떤 사실·해석에 기대고 있나? |
| **행동** | 그래서 할 일 | 판단이 틀려도 여전히 할 만한가? |

층을 붙이고 나면 대개 이런 게 드러난다:

- **사실이 없는 판단** — 해석과 감정만으로 결론까지 간 경우
- **감정을 사실로 착각** — "안 풀린다"가 관찰인지 기분인지 불분명한 경우
- **판단 없는 행동** — 왜 하는지 모른 채 하고 있는 일

### 4단계 — 캐묻기 (Probe)

3단계에서 드러난 빈 곳만 골라 묻는다. 한 라운드 3개 이하.

층별 기본 질문:

| 대상 | 질문 |
| --- | --- |
| 사실 | "그렇게 판단한 근거가 되는 구체적인 장면이 뭐였나요?" |
| 해석 | "같은 일을 정반대로 해석한다면 어떤 이야기가 되나요?" |
| 감정 | "그 감정이 없었다면 같은 결론이었을까요?" |
| 판단 | "이 판단이 틀리려면 무엇이 참이어야 하나요?" |
| 행동 | "이걸 안 하면 3개월 뒤에 뭐가 달라지나요?" |
| 전체 | "지금 이 중에 제일 확신 없는 게 뭔가요?" |

답이 안 나오면 **그 자리에서 열린 질문으로 굳혀 기록**한다. 답 못 낸 질문이 남는 건 실패가 아니라 이 방법의 정상 산출물이다.

### 5단계 — 압축 (Compress)

각 조각을 **제목만 읽어도 뜻이 통하는 한 문장**으로 줄인다. 이게 곧 원자 노트의 제목이 된다.

- 명사구가 아니라 **서술문**으로 쓴다. (`매몰비용` ❌ / `지금까지 쓴 시간은 방향 결정의 근거가 못 된다` ⭕)
- 압축이 안 되면 아직 한 조각이 아니다 → 2단계로 되돌아간다.

그리고 조각들 사이의 관계를 정한다:

- A가 B의 **근거**다 → A의 부모는 B
- A가 B의 **반례**다 → A의 부모는 B, 본문 `## 반론 / 빈 곳` 에 명시
- A와 B가 **같은 층의 형제**다 → 둘 다 주제 허브가 부모

## 세션을 마칠 때 반드시 남기는 것

1. 이번에 **확정된 판단** 하나 (없으면 "없음"이라고 적는다 — 억지로 만들지 않는다)
2. **가장 확신 없는 지점** 하나
3. **다음에 팔 질문** 하나

이 세 줄이 다음 세션의 시작점이 된다.
