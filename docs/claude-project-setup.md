# Claude 프로젝트로 옮기기

생각 정리 시스템을 **Claude Code Projects** 로 옮기는 절차입니다.

프로젝트는 하나의 이어지는 대화이고, 작업 하나하나는 **스레드**(클라우드 세션)로 갈라져 돌아갑니다. 중요한 건 이겁니다 — **스레드는 프로젝트에 붙인 저장소를 클론하고, 거기 있는 `CLAUDE.md` 와 `.claude/skills/` 를 시작할 때 전부 읽습니다.** 그래서 `thought-organizer` 스킬과 `tools/vault.mjs` 가 그대로 살아 있고, 노션 커넥터도 클라우드 스레드에서 쓸 수 있습니다. 옵시디언 쪽을 잃지 않습니다.

> claude.ai **채팅**의 프로젝트와는 다릅니다. 채팅 프로젝트는 지침과 지식 파일만 갖고 셸이나 git이 없어서, 볼트 파일을 만들 수 없습니다. 아래는 `claude.ai/code` 의 프로젝트입니다.

## 1. 기본 브랜치 확인

## 태도

- 내가 말하는 중에는 자르지 않는다. 다 뱉을 때까지 "계속하세요." 외에는 말하지 않는다.
- 되비추기(요약 확인) 단계를 건너뛰지 않는다. 잘못 들은 채로 기록하면 볼트가 오염된다.
- 질문은 한 라운드에 3개 이하. 음성으로 답해야 한다.
- 내가 안 한 말을 지어내지 않는다. 추론한 부분은 (추론) 이라고 표시한다.
- 칭찬이나 추임새를 넣지 않는다. 짧고 담백하게.

## 브랜치와 커밋

- 볼트 변경(vault/ 아래)은 main 에 직접 커밋하고 푸시한다. PR을 만들지 않는다. 내가 로컬에서 git pull 만으로 노트를 받아야 하기 때문이다.
- 도구나 스킬 코드 변경(tools/, .claude/, docs/ 등)은 브랜치를 따고 PR을 만든다.
- 볼트를 건드린 뒤에는 항상 npm run vault:build 를 돌려 지도와 대시보드를 다시 만들고, check 가 초록이 된 뒤에 커밋한다.

## 조회 요청

"내가 X에 대해 뭐라고 했었지" 같은 조회는 새 스레드를 만들지 말고 기존 스레드나 대화에서 답한다. node tools/vault.mjs list 로 찾아 읽고 답하면 된다.

## 5. 실제로 쓰는 법 — 여기 주의가 필요합니다

프로젝트 **대화 자체에는 커넥터가 없습니다.** 노션에 쓰는 일은 스레드에서만 됩니다. 그리고 인터뷰는 주고받아야 하니까, 실제 흐름은 이렇게 됩니다.

1. 프로젝트 대화에 **"생각 정리 시작"** 이라고만 보냅니다
2. Claude가 스레드를 하나 열고 카드로 띄웁니다
3. **그 카드를 눌러 스레드 안으로 들어가서**, 거기서 음성으로 쏟아냅니다
4. 인터뷰도 그 스레드 안에서 주고받습니다
5. 끝나면 스레드가 노션 페이지 링크와 볼트 커밋 결과를 보고합니다

한 번 더 누르는 게 늘지만, 대신 얻는 게 있습니다 — 지침이 매 세션 자동으로 적용되고, 프로젝트 메모리에 결정과 교정이 누적되고, 세션들이 한 곳에 모입니다. 지금처럼 매번 새 세션을 파면 그게 안 됩니다.

**교정은 기억시키세요.** 스레드가 뭘 잘못했을 때 고쳐주는 것으로 끝내지 말고 "이거 기억해둬" 라고 말하면 프로젝트 메모리에 들어가서 다음 스레드가 그걸 갖고 시작합니다. 방법론을 다듬어 나가는 데 이게 제일 중요합니다.

Claude 모바일 앱(iOS·안드로이드)의 **Code** 탭에 프로젝트가 그대로 보입니다. 스레드를 열어 음성으로 말하고, 돌아가는 상태를 보고, 답을 줄 수 있습니다. 클라우드 스레드는 앱을 닫아도 계속 돕니다.

볼트 열람은 [옵시디언 설치와 동기화](setup-obsidian.md) 를 보세요.

## 알아둘 제약

- 공개 베타, **Pro·Max 전용**. 팀·엔터프라이즈는 아직 안 됩니다
- 터미널 CLI에서는 프로젝트를 쓸 수 없습니다 (claude.ai/code, 데스크톱 앱, 모바일 앱만)
- **프로젝트는 한 사람 것입니다.** 다른 사람과 공유할 수 없습니다
- 스레드는 만든 프로젝트에 묶입니다. 다른 프로젝트로 옮길 수 없습니다
- 스레드 샌드박스는 턴 사이에 멈췄다 재개되는데, 재개가 실패하면 새 클론에서 이어지면서 **커밋 안 한 변경이 사라질 수 있습니다.** 그래서 지침에 "볼트 변경은 그때그때 커밋·푸시" 를 넣어뒀습니다
- 이미 돌고 있는 스레드에는 설정 변경이 반영되지 않습니다. 새 스레드부터 적용됩니다
